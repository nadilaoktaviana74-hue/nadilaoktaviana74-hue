## 🚀 Featured Projects

### 📋 Pranata Gatra Web

**A web platform focused on version control and application publishing for Pranata Gatra, a collaborative To-Do List application.**

Pranata Gatra Web is designed to support the development and distribution workflow of the Pranata Gatra application. The platform focuses on managing application versions and providing a centralized platform for publishing application builds.

**Key Focus:**
- Application version control
- Application build publishing
- Release management
- Collaborative application development
- Centralized application distribution

**Tech Stack:**

`Next.js` `PostgreSQL` `Tailwind CSS`

---

### 🛍️ Preniche

**A campus-focused thrift marketplace for students looking to buy and sell items useful for campus life and boarding needs.**

Preniche is a specialized marketplace designed for students within a specific university community. The platform provides a space for students to exchange pre-owned items, particularly products related to campus activities, study needs, and everyday boarding life.

**Key Focus:**
- Student-focused marketplace
- Thrift and second-hand products
- Campus community interaction
- Product listing and discovery
- Practical and sustainable consumption

**Tech Stack:**

`TypeScript` `PostgreSQL` `Prisma ORM` `Tailwind CSS`
